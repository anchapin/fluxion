# `assets/weather/` provenance

Weather files used by the fluxion validation suites. ASHRAE 140 Section 6 conformance is a
claim *about reading these exact files*, so their provenance and integrity are part of the
evidence, not incidental build assets.

Generated by inspecting the committed files. Verify with `sha256sum -c CHECKSUMS.txt`.

### WD100 and WD600 differ in exactly one field

`WD100.epw` is 1 496 423 bytes, `WD600.epw` is 1 513 943 bytes. The 17 520-byte delta is
exactly 2.0 bytes per data row. All eight header lines (LOCATION, DESIGN CONDITIONS,
TYPICAL/EXTREME PERIODS, GROUND TEMPERATURES, HOLIDAYS/DAYLIGHT SAVINGS, COMMENTS 1,
COMMENTS 2, DATA PERIODS) are identical.

Diffing all 35 EPW fields across all 8760 rows, exactly one field differs, in every row:

```
field 32 (albedo):   WD100 = 0      WD600 = 0.2
```

Every other field, including drybulb, dewpoint, RH, pressure, GHI, DNI, DHI, horizontal IR,
wind direction, wind speed and sky cover, is byte-identical.

This makes the pair a clean single-variable isolation of ground-reflected shortwave: same
site, same year, same sky, ground reflectance 0 against 0.2.

**Consequence for the engine:** albedo must be read per hour from EPW field 32, not from a
configuration constant. An engine that hardcodes ground reflectance returns identical
results for WD100 and WD600 and looks self-consistent while failing the test outright.

### Format note

Each case is committed in two formats, `.epw` and `.tmy3`. The `.tmy3` files carry the
TMY3 CSV header (`WMO,"NAME",ST,TZ,lat,lon,elev`) and 8761 lines including the column-name
row; the `.epw` files carry the eight-line EPW header and 8768 lines. Both encode the same
8760 hours.

**Unresolved:** the conversion tooling that produced these two representations is not
recorded anywhere in the repository, and neither is the ASHRAE distribution they were
derived from. Both need to be established and written here before a Section 6 conformance
claim is published. Do not treat the table above as a provenance chain; it is a description
of what the committed bytes contain.
