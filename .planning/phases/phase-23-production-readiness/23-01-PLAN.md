### Task 4: Create Usage Examples for Common Workflows

**Type:** implementation
**Time:** 5 minutes

**Actions:**
1. Create 3 core workflow examples in `examples/`:

   **examples/optimization_workflow.py:**
   ```python
   """
   Building parameter optimization with Fluxion.

   This example demonstrates how to optimize building parameters
   (insulation thickness, window area, HVAC capacity) to minimize
   annual energy consumption while maintaining comfort constraints.
   """
   from fluxion import BatchOracle, Model
   import numpy as np

   # Initialize oracle
   oracle = BatchOracle()

   # Define parameter space
   param_space = {
       'wall_insulation_thickness': np.linspace(0.05, 0.30, 10),  # meters
       'window_area_ratio': np.linspace(0.1, 0.4, 5),
       'hvac_capacity': np.linspace(5000, 15000, 8),  # Watts
   }

   # Run optimization
   results = oracle.optimize(
       objective='minimize_annual_energy',
       param_space=param_space,
       constraints={'comfort_hours': lambda x: x > 8000},  # >8000 comfortable hours
       n_iterations=100
   )

   # Analyze results
   print(f"Best configuration: {results.best_params}")
   print(f"Annual energy: {results.best_energy:.2f} MWh")
   ```

   **examples/validation_workflow.py:**
   ```python
   """
   ASHRAE 140 validation workflow.

   Comprehensive validation against ASHRAE Standard 140
   analytical and empirical test cases.
   """
   from fluxion import BatchOracle

   oracle = BatchOracle()

   # Run full validation suite
   results = oracle.validate_all()

   # Check compliance
   passing = sum(1 for r in results if abs(r.error_percent) < 15)
   print(f"Passing: {passing}/{len(results)} cases (±15% tolerance)")

   # Generate report
   oracle.generate_validation_report(output_dir='./validation_report')
   ```

   **examples/analysis_workflow.py:**
   ```python
   """
   Building energy analysis workflow.

   Analyze building performance under different weather conditions,
   occupancy schedules, and HVAC configurations.
   """
   from fluxion import Model
   import pandas as pd

   # Load building model
   model = Model.from_config('building_config.json')

   # Run annual simulation
   results = model.simulate(weather_file='weather.epw')

   # Extract time series
   hourly_energy = results.hourly_energy  # kWh
   hourly_loads = results.hourly_loads    # Watts

   # Analyze monthly patterns
   monthly = hourly_energy.resample('M').sum()
   print(monthly)

   # Export results
   results.to_csv('simulation_results.csv')
   ```
