Create src/validation/thermal_mass_energy_accounting.rs with energy balance validation:

1. Define EnergyBalanceReport struct:
   ```rust
   pub struct EnergyBalanceReport {
       pub cumulative_error: f64,      // Σ|balance_error| over timesteps
       pub error_pct: f64,              // (cumulative_error / total_energy) * 100
       pub is_valid: bool,              // true if error_pct < 0.01%
       pub hourly_errors: Vec<f64>,      // balance_error for each timestep
       pub energy_in_total: f64,         // Total energy entering system
       pub energy_out_total: f64,        // Total energy leaving system
   }
   ```

2. Implement calculate_mass_energy(model) -> f64:
   - E = Σ(Cm_i * Tm_i) for all mass nodes i
   - Sum: thermal_capacitance[i] * mass_temperatures[i]
   - Returns total thermal mass energy (Joules)

3. Implement validate_energy_balance_over_year(model) -> EnergyBalanceReport:
   - Initialize cumulative_error = 0.0, energy_in_total = 0.0, energy_out_total = 0.0
   - Get initial mass_energy = calculate_mass_energy(model)
   - For each timestep (0..8760):
     - Calculate energy_in: heating_energy[t] + cooling_energy[t] + solar_gains[t] + infiltration_gains[t]
     - Run timestep: model.step_physics(t, weather_temp)
     - Calculate energy_out: hvac_demand[t]
     - Calculate current_mass_energy = calculate_mass_energy(model)
     - Calculate balance_error = energy_in - energy_out - (current_mass_energy - initial_mass_energy)
     - Append balance_error to hourly_errors
     - cumulative_error += balance_error.abs()
     - energy_in_total += energy_in
     - energy_out_total += energy_out
   - Calculate error_pct = (cumulative_error / energy_in_total.max(energy_out_total)) * 100.0
   - Set is_valid = error_pct < 0.01
   - Return EnergyBalanceReport

4. Add #[cfg(test)] tests module for basic functionality

Key insight: Energy balance validates physics correctness, not accuracy. If error_pct < 0.01%, physics is conserving energy even if annual energy predictions are wrong (fundamental 5R1C limitation, not a bug).
