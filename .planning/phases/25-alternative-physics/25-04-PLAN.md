## Implementation Details

### CTF Coefficient Calculation Algorithm

**Step 1: Transmission Matrix per Layer**
```
For layer k with thickness L_k, conductivity k_k, diffusivity α_k:

M_k = [cosh(γ_k·L_k),  sinh(γ_k·L_k)/(k_k·γ_k)]
      [k_k·γ_k·sinh(γ_k·L_k), cosh(γ_k·L_k)]

where γ_k = sqrt(s/α_k) (s is Laplace variable)
```

**Step 2: Full Wall Matrix**
```
M_total = M_1 × M_2 × ... × M_n
```

**Step 3: Transfer Functions**
```
H_X(s) = exterior flux / exterior temp (from M_total)
H_Y(s) = interior flux / exterior temp
H_Z(s) = interior flux / interior temp
```

**Step 4: Partial Fraction Expansion**
```
H(s) = Σ (r_j / (s - p_j))  (sum over poles p_j with residues r_j)
```

**Step 5: CTF Coefficients (time domain)**
```
X_j = Σ r_X,k · exp(p_k · j·Δt)
Y_j = Σ r_Y,k · exp(p_k · j·Δt)
Z_j = Σ r_Z,k · exp(p_k · j·Δt)
Φ_j = coefficients from flux history
```

### CTF Heat Balance Equation

```
Interior surface heat flux at timestep t:

q''_interior,t = -Z₀·T_i,t + Σⱼ(X_j·T_e,t-j) - Σⱼ(Y_j·T_i,t-j) - Σⱼ(Φ_j·q''_t-j)

where:
- T_i,t = interior surface temperature at time t
- T_e,t = exterior surface temperature at time t
- X_j, Y_j, Z_j = CTF coefficients (j = 0, 1, 2, ...)
- Φ_j = flux history coefficients
- Summation typically uses 10-20 terms (j = 0 to 10-20)
```

### Computational Complexity

**CTF Coefficient Calculation (one-time, precomputation):**
- O(n_layers × n_poles) for transmission matrix + partial fractions
- ~10-100 ms per construction

**CTF Runtime (per timestep):**
- O(n_surfaces × n_coefficients) for heat flux calculation
- ~6 surfaces × 15 coefficients = 90 multiply-add operations
- ~800-1,200 configs/sec throughput expected

## Notes

- **CTF vs. FD:** CTF is frequency-domain (precomputed), FD is time-domain (runtime)
- **Accuracy:** CTF and FD should match closely (both solve same heat equation)
- **Performance:** CTF faster at runtime (no matrix solve), but requires precomputation
- **EnergyPlus:** Uses CTF as primary conduction solver (validated approach)
- **Limitations:** CTF assumes constant material properties (no temperature dependence)
