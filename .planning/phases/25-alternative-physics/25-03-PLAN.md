## Goal

Implement 1D finite difference heat conduction through building envelope layers to replace lumped capacitance model. This captures thermal lag through multi-layer walls accurately, matching EnergyPlus physics for high-mass buildings.

### Task 3: Implicit Finite Difference Solver

**What to do:**
- Implement `ImplicitFDSolver` struct
- Assemble tridiagonal coefficient matrix (A, B, C coefficients)
- Solve linear system using Thomas algorithm (TDMA)
- Apply boundary conditions (surface convection, radiation)
- Advance solution by one timestep

**Deliverable:** `src/physics/fd_solver.rs`

**Verification:**
- [ ] Matrix assembly correct (tridiagonal structure)
- [ ] Thomas algorithm implemented and tested
- [ ] Boundary conditions applied correctly
- [ ] Unit tests: analytical solution comparison (1D slab with known BCs)
- [ ] Accuracy: <1% error vs. analytical solution

**Mathematical Form:**
```
Implicit scheme: (T_i^(n+1) - T_i^n) / Δt = α (T_{i+1}^(n+1) - 2T_i^(n+1) + T_{i-1}^(n+1)) / Δx²

Tridiagonal system:
A_i · T_{i-1}^(n+1) + B_i · T_i^(n+1) + C_i · T_{i+1}^(n+1) = D_i
```

### Task 4: Surface Heat Balance Coupling

**What to do:**
- Couple FD wall model to zone air heat balance
- Interior surface: convection (h_c,i) + radiation (LW + SW) + conduction
- Exterior surface: convection (h_c,e) + radiation (LW + solar) + conduction
- Solve coupled system (zone air temp + wall node temps)

**Deliverable:** `src/physics/fd_surface_balance.rs`

**Verification:**
- [ ] Interior surface heat balance correct
- [ ] Exterior surface heat balance correct (includes sol-air temperature)
- [ ] Coupled solver converges (residual < 1e-6)
- [ ] Unit tests: energy balance at surfaces

**Coupling Equation:**
```
Zone air: C_zone · dT_zone/dt = Σ h_c,i · A_i · (T_surf,i - T_zone) + Q_HVAC + Q_internal

Surface i: -k · dT/dx|_surf = h_c,i · (T_surf - T_zone) + q_radiation
```

## Implementation Details

### Discretization Strategy

**Recommended:** 10 nodes per layer (40 nodes total for 4-layer Case 900 wall)

```
Layer 1 (brick, 100mm):     nodes 0-9
Layer 2 (insulation, 50mm): nodes 10-19
Layer 3 (concrete, 150mm):  nodes 20-29
Layer 4 (gypsum, 13mm):     nodes 30-39
```

### Matrix Structure (Implicit Scheme)

```
Tridiagonal system for 40 nodes:
┌                    ┐
│ B₀  C₀   0   ...   │
│ A₁  B₁  C₁   ...   │
│  0  A₂  B₂  C₂ ... │
│ ...               │
│            Aₙ  Bₙ  │
└                    ┘

Solved in O(n) operations using Thomas algorithm
```

### Boundary Conditions

**Interior Surface (node 0):**
```
-k · (T₁ - T₀) / Δx = h_c,i · (T₀ - T_zone) + q_radiation,i
```

**Exterior Surface (node n):**
```
-k · (Tₙ - Tₙ₋₁) / Δx = h_c,e · (Tₙ - T_solair) + q_radiation,e
```

---

## Notes

- **Scheme Choice:** Implicit (first-order, unconditionally stable) for robustness
- **Node Count:** 10 nodes/layer is sweet spot (accuracy vs. performance)
- **Performance:** ~40 nodes × 8760 timesteps = ~350K node updates per simulation
- **Future Optimization:** Can use adaptive node refinement (fine near surfaces, coarse in core)
- **Comparison to 5R1C:** FD is ~10-20× more computation but ~10× more accurate for high-mass
