# Plan 25-02: Adaptive Timestep Implementation

**Type:** Implementation
**Effort:** 1-2 weeks
**Dependencies:** 25-00 (literature review)
**Checkpoint:** checkpoint:human-verify (verify timestep adaptation logic and accuracy improvement)

---

## Goal

Implement adaptive timestep integration for high-mass buildings to improve numerical accuracy. Reduce timestep from 1-hour to 6-minute or 1-minute for buildings with thermal mass time constants exceeding threshold.

---

## Tasks

### Task 1: Time Constant Analysis and Threshold Definition

**What to do:**
- Analyze thermal mass time constant τ = C / (h_tr_ms + h_tr_em)
- Calculate τ for all ASHRAE 140 cases (600-series, 900-series)
- Define threshold: τ > τ_threshold → use adaptive timestep
- Document relationship between τ and optimal timestep Δt

**Deliverable:** `docs/ADAPTIVE_TIMESTEP_THEORY.md` with:
- Time constant calculations for all test cases
- Threshold recommendation (e.g., τ > 2 hours → Δt ≤ 6 min)
- Stability analysis (CFL-like condition for RC networks)

**Verification:**
- [ ] Time constant calculated for Case 600, 650, 900, 920, 930, 940, 960
- [ ] Threshold justified by numerical stability analysis
- [ ] Recommended timestep table: τ range → Δt

**Expected Values:**
- Case 600 (low-mass): τ ≈ 0.5-1 hour → Δt = 1 hour OK
- Case 900 (high-mass): τ ≈ 4-5 hours → Δt = 6 min required

## Expected Accuracy Improvement

**Hypothesis:** Adaptive timestep will improve accuracy but NOT achieve ±15% target.

**Rationale:**
- Current error (229-322%) is dominated by 5R1C structural limitation, not just timestep
- Timestep too coarse (Δt/τ ≈ 0.2 vs. recommended <0.1) contributes ~20-30% error
- Fine timestep (Δt/τ ≈ 0.02) should reduce timestep error to <5%
- Remaining error (~50-100%) is fundamental 5R1C limitation

**Prediction:**
- Case 900 heating: 5.35 MWh (baseline) → 2.5-3.5 MWh (adaptive)
- Still 70-120% above reference (1.17-2.04 MWh), but significant improvement

---

## Notes

- **Timestep Selection:** 6-minute (10 timesteps/hour) recommended for high-mass
- **Stability:** Explicit Euler stable if Δt < 2C / Σh (typically Δt < 30 min for high-mass)
- **Performance Cost:** 10× more timesteps = ~4-5× slower (not 10× due to fixed overhead)
- **Future Work:** Can combine with ML surrogate to correct remaining error
