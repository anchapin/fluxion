**Type:** Implementation (ML Surrogate)
**Effort:** 2 weeks

## Goal

Implement hybrid approach: keep fast 5R1C RC network physics, train ML surrogate to predict residual error (difference between 5R1C and EnergyPlus ground truth). Apply ML correction post-simulation to achieve high accuracy without physics changes.

## Implementation Details

### ML Model Architecture (Recommended: MLP)

```python
# PyTorch example
class ResidualPredictor(nn.Module):
    def __init__(self, input_dim=20, hidden_dim=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1)  # Output: residual error (MWh)
        )

    def forward(self, x):
        return self.net(x)
```

### Training Loss Function

```python
# Huber loss (robust to outliers)
loss = nn.HuberLoss(delta=0.5)

# Or MSE with L2 regularization
loss = MSE(pred, target) + lambda * L2_norm(weights)
```

### Feature Normalization

```rust
// Z-score normalization (precomputed from training data)
feature_normalized = (feature - mean) / std_dev

// Example: thermal capacitance
// mean = 20e6 J/K, std_dev = 10e6 J/K
// C = 19,944,509 J/K → C_normalized = (19.9e6 - 20e6) / 10e6 = -0.0055
```
