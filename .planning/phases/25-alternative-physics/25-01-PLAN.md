# Plan 25-01: EnergyPlus SDK Installation and Data Generation

**Type:** Infrastructure & Data Generation
**Effort:** 3-4 days
**Dependencies:** None (parallel with 25-00)
**Checkpoint:** checkpoint:human-verify (verify EnergyPlus installation and test case results)

---

## Goal

Install EnergyPlus or OpenStudio SDK and generate high-fidelity simulation data for Case 900 (high-mass building) to use as ground truth for training ML surrogates and validating alternative physics implementations.

---

## Tasks

### Task 1: EnergyPlus Installation

**What to do:**
- Download EnergyPlus v23.1+ from GitHub releases
- Install EnergyPlus with command-line tools
- Verify installation with `energyplus --version`
- Locate EnergyPlus example files and weather data

**Deliverable:** EnergyPlus v23.1+ installed and functional

**Verification:**
- [ ] `energyplus --version` returns v23.1 or later
- [ ] Example files accessible (typically `/usr/local/share/energyplus/` or `C:\EnergyPlusV23-1-0\ExampleFiles`)
- [ ] Weather data accessible (typically `/usr/local/share/energyplus/WeatherData/`)
- [ ] Python API (if available) functional: `python -c "import energyplus"`

---

### Task 2: ASHRAE 140 Case 900 IDF File Creation

**What to do:**
- Create EnergyPlus IDF (Input Data File) for ASHRAE 140 Case 900
- Match Fluxion input parameters exactly:
  - Building geometry: 8m × 6m × 2.7m zone
  - Wall construction: 4 layers (exterior brick, insulation, concrete, gypsum)
  - Thermal mass: 19,944,509 J/K total capacitance
  - Windows: 4 m² south-facing, U-value 2.8 W/m²K
  - HVAC: ideal loads system (heating setpoint 20°C, cooling 25°C)
  - Location: Denver, CO (TMY2 weather file)
  - Timestep: 60 (1-hour timesteps)

**Deliverable:** `tests/energyplus_data/case_900.idf`

**Verification:**
- [ ] IDF file passes EnergyPlus input validation
- [ ] Geometry matches Fluxion Case 900 specification
- [ ] Construction layers match thermal properties (U-value, mass, R-value)
- [ ] HVAC setpoints match (20°C heating, 25°C cooling)
- [ ] Weather file: Denver TMY2 (USA_CO_Denver.Intl.AP.724699_TMY2.epw)

---

### Task 3: EnergyPlus Baseline Simulation (Case 900)

**What to do:**
- Run EnergyPlus simulation for Case 900 IDF
- Extract hourly results: zone temperature, HVAC heating/cooling rates
- Extract monthly results: heating energy, cooling energy
- Extract annual totals: annual heating (MWh), annual cooling (MWh)

**Deliverable:** `tests/energyplus_data/case_900_results.csv`

**Verification:**
- [ ] Simulation completes without errors
- [ ] Hourly results: 8760 timesteps (full year)
- [ ] Monthly energy totals extracted (12 months × heating + cooling)
- [ ] Annual energy calculated (MWh)
- [ ] Results compared to ASHRAE 140 reference ranges:
  - Annual heating: 1.17-2.04 MWh
  - Annual cooling: 2.13-3.67 MWh

**Expected Results (from ASHRAE 140):**
- Annual Heating: ~1.5-1.8 MWh (within 1.17-2.04 MWh reference)
- Annual Cooling: ~2.8-3.2 MWh (within 2.13-3.67 MWh reference)

---

### Task 4: Parametric Sweep - Mass Level Variation

**What to do:**
- Create 5 IDF variants with different thermal mass levels:
  - Case 900-Light: 50% mass (9,972,254 J/K)
  - Case 900-Medium: 100% mass (19,944,509 J/K) - baseline
  - Case 900-Heavy: 150% mass (29,916,763 J/K)
  - Case 900-VHeavy: 200% mass (39,889,018 J/K)
  - Case 900-XHeavy: 300% mass (59,833,527 J/K)
- Run EnergyPlus simulation for each variant
- Extract annual heating and cooling energy

**Deliverable:** `tests/energyplus_data/case_900_mass_sweep.csv`

**Verification:**
- [ ] 5 IDF files created with varying mass
- [ ] All 5 simulations complete successfully
- [ ] Annual energy extracted for each case
- [ ] Mass vs. energy relationship plotted (expect non-linear due to thermal lag)

**Purpose:** Generate training data for ML surrogate to learn mass-energy relationship

---

### Task 5: Parametric Sweep - Timestep Sensitivity

**What to do:**
- Run Case 900 baseline with 6 different timesteps:
  - 60 timesteps/hour (1-minute)
  - 10 timesteps/hour (6-minute)
  - 4 timesteps/hour (15-minute)
  - 2 timesteps/hour (30-minute)
  - 1 timestep/hour (60-minute) - baseline
  - 0.5 timesteps/hour (2-hour)
- Extract annual energy for each timestep
- Analyze convergence (energy vs. timestep)

**Deliverable:** `tests/energyplus_data/case_900_timestep_sweep.csv`

**Verification:**
- [ ] 6 simulations complete successfully
- [ ] Annual energy extracted for each timestep
- [ ] Convergence plot: energy vs. timestep (log scale)
- [ ] Identify timestep where energy converges (ΔE < 1% for finer timesteps)

**Expected:** Energy converges at ~6-minute timestep (10 timesteps/hour)

**Purpose:** Determine optimal timestep for Fluxion adaptive timestep implementation

### Task 7: Hourly Profile Extraction

**What to do:**
- Run Case 900 baseline with full hourly output
- Extract 8760 hourly values for:
  - Zone air temperature (°C)
  - Mean radiant temperature (°C)
  - Operative temperature (°C)
  - HVAC heating rate (W)
  - HVAC cooling rate (W)
  - Surface inside face temperature (all 4 walls, floor, ceiling)
  - Surface outside face temperature (all 4 walls, floor, ceiling)
  - Solar gain through windows (W)
  - Conduction heat flux through walls (W/m²)

**Deliverable:** `tests/energyplus_data/case_900_hourly_profiles.csv`

**Verification:**
- [ ] CSV has 8760 rows (one per hour)
- [ ] All 15+ output variables extracted
- [ ] No missing values or NaN
- [ ] Temperature profiles physically reasonable (15-30°C range)
- [ ] HVAC profiles show expected seasonal pattern

**Purpose:** Training data for ML surrogate to learn temporal dynamics

## Notes

- **EnergyPlus Version:** Use v23.1+ for latest CTF implementation
- **Weather File:** Denver TMY2 (required for ASHRAE 140 compliance)
- **Timestep:** EnergyPlus default is 6 timesteps/hour; use 60 for high accuracy
- **Output Variables:** Request all hourly outputs in IDF `Output:Variable` objects
- **Python API:** EnergyPlus Python API optional but useful for automation
- **OpenStudio Alternative:** If EnergyPlus CLI is difficult, use OpenStudio SDK (Ruby/Python bindings)
