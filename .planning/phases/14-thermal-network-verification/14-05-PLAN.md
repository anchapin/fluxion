<objective>
Resolve conflict between thermal mass correction (Plan 14-02) and mode-specific coupling (Plan 14-03) to achieve ASHRAE 140 compliance for high-mass buildings.

Purpose: Current implementation applies mode-specific factors (heating_factor=0.55, cooling_factor=1.75) to thermal mass correction target values, causing coupling ratio to deviate from target. This results in annual energy error of 229-322% instead of target ±15% for Case 900.

Resolution Strategy (Option B): Adjust thermal mass correction to account for mode-specific factors by computing separate target values for heating and cooling modes, then applying mode-specific factors to achieve the desired coupling ratio in each mode.

Output: Corrected thermal mass correction that achieves coupling ratio > 0.1 in both heating and cooling modes, reducing annual energy error to within ±15% tolerance.
</objective>

    Modify apply_thermal_mass_correction() method to resolve conflict with mode-specific coupling factors:

    Current problematic behavior (lines 1549-1569):
    1. Calculates target_h_tr_em = 0.1 * h_tr_ms (to achieve ratio > 0.1)
    2. Applies mode-specific factors: h_tr_em_heating = target_h_tr_em * 0.55, h_tr_em_cooling = target_h_tr_em * 1.75
    3. Result: Actual coupling ratios deviate from target (0.1 * 0.55 = 0.055 heating, 0.1 * 1.75 = 0.175 cooling)

    Resolution (Option B - chosen for accuracy):
    Compute separate target values for heating and cooling modes that account for mode-specific factors:

    ```rust
    pub fn apply_thermal_mass_correction(&mut self) {
        let total_cap: f64 = self.thermal_capacitance.iter().sum();

        // Early exit for low-mass buildings
        if total_cap <= HIGH_MASS_THRESHOLD {
            return;
        }

        // Calculate structure thermal capacitance (excluding air)
        let zone_area = self.zone_area[0];
        let air_cap = zone_area * 1.2 * 1005.0; // J/K (density * specific_heat * air_mass)
        let structure_cap = total_cap - air_cap;

        // ASHRAE 140: High-mass buildings have >3x low-mass capacitance
        // Low-mass (Case 600): 2.4e6 J/K, High-mass (Case 900): 1.2e7 J/K
        // Threshold: 5e6 J/K (between low and high mass)
        if structure_cap < HIGH_MASS_THRESHOLD {
            return;
        }

        // Calculate current coupling ratio: h_tr_em / h_tr_ms
        let h_tr_ms_value: f64 = self.h_tr_ms.as_ref()[0];
        let h_tr_em_value: f64 = self.h_tr_em.as_ref()[0];
        let current_ratio = h_tr_em_value / h_tr_ms_value;

        // Target ratio > 0.1 (ASHRAE 140 requirement)
        let target_ratio = 0.1;

        if current_ratio >= target_ratio {
            return; // Already compliant
        }

        // RESOLUTION: Compute separate target values for heating and cooling modes
        // This accounts for mode-specific factors to achieve desired coupling ratio in each mode
        // Formula: target_h_tr_em_mode = (target_ratio / mode_factor) * h_tr_ms

        let heating_factor = self.h_tr_em_heating_factor;
        let cooling_factor = self.h_tr_em_cooling_factor;

        // Target heating coupling: achieve ratio 0.1 when heating_factor is applied
        // target_h_tr_em_heating * heating_factor = 0.1 * h_tr_ms
        // Therefore: target_h_tr_em_heating = (0.1 / heating_factor) * h_tr_ms
        let target_h_tr_em_heating = (target_ratio / heating_factor) * h_tr_ms_value;

        // Target cooling coupling: achieve ratio 0.1 when cooling_factor is applied
        // target_h_tr_em_cooling * cooling_factor = 0.1 * h_tr_ms
        // Therefore: target_h_tr_em_cooling = (0.1 / cooling_factor) * h_tr_ms
        let target_h_tr_em_cooling = (target_ratio / cooling_factor) * h_tr_ms_value;

        // Update base h_tr_em to average of heating/cooling targets (for consistency)
        let target_h_tr_em = (target_h_tr_em_heating + target_h_tr_em_cooling) / 2.0;
        let h_tr_em_data = self.h_tr_em.as_mut();
        h_tr_em_data.iter_mut().for_each(|v| *v = target_h_tr_em);

        // Update mode-specific coupling values with corrected targets
        for v in self.h_tr_em_heating.as_mut().iter_mut() {
            *v = target_h_tr_em_heating;
        }
        for v in self.h_tr_em_cooling.as_mut().iter_mut() {
            *v = target_h_tr_em_cooling;
        }

        // Debug output (can be removed after validation)
        if cfg!(debug_assertions) {
            println!("DEBUG: Thermal mass correction with mode-specific factors:");
            println!("  Heating factor: {:.2}", heating_factor);
            println!("  Cooling factor: {:.2}", cooling_factor);
            println!("  Target h_tr_em_heating: {:.2} W/K", target_h_tr_em_heating);
            println!("  Target h_tr_em_cooling: {:.2} W/K", target_h_tr_em_cooling);
            println!("  Base h_tr_em: {:.2} W/K", target_h_tr_em);
            println!("  Expected heating ratio: {:.3}", (target_h_tr_em_heating * heating_factor) / h_tr_ms_value);
            println!("  Expected cooling ratio: {:.3}", (target_h_tr_em_cooling * cooling_factor) / h_tr_ms_value);
        }
    }
    ```

    Key changes:
    1. Remove lines 1549-1579 (problematic mode-specific factor multiplication)
    2. Add calculation of target_h_tr_em_heating and target_h_tr_em_cooling using formula: (target_ratio / factor) * h_tr_ms
    3. Update h_tr_em_heating and h_tr_em_cooling with pre-corrected target values (not multiplied by factors)
    4. Update base h_tr_em to average of heating/cooling targets for consistency

    Rationale for Option B:
    - Preserves mode-specific coupling behavior (heating/cooling factors still applied)
    - Achieves target coupling ratio in both modes
    - More accurate than Option A (disable mode-specific coupling) because heating/cooling asymmetry is physically meaningful
    - Cleaner than Option D (mutually exclusive config) because it integrates both corrections seamlessly
