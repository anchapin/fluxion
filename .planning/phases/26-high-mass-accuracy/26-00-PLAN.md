# Plan 26-00: Comparative Evaluation of Alternative Physics Methods

**Phase:** 26 - High-Mass Accuracy
**Plan:** 26-00 - Comparative Evaluation
**Type:** Evaluation & Benchmarking
**Effort:** 1 week
**Dependencies:** Phase 25 complete (all 6 alternative physics methods implemented)

---

## Goal

Comprehensive comparison of all implemented alternative physics approaches from Phase 25. Evaluate accuracy, performance, and implementation complexity to recommend the best approach for production use in improving high-mass building simulation accuracy.

---

## Methods to Compare

| Method | Description | Expected Accuracy | Expected Throughput |
|--------|-------------|-------------------|---------------------|
| **5R1C Baseline** | ISO 13790 5R1C thermal network | ±200-300% (high-mass) | ~2,575 configs/sec |
| **Adaptive Timestep** | Variable timestep (6-min for high-mass) | ±70-120% | ~600 configs/sec |
| **Finite Difference** | 1D implicit BTCS heat conduction | ±3-5% | ~500 configs/sec |
| **CTF** | Conduction Transfer Functions | ±3-5% | ~800 configs/sec |
| **ML Correction** | 5R1C + neural network residual | ±15-30% | ~2,300 configs/sec |

---

## Evaluation Criteria

### 1. Accuracy (40% weight)

**Metrics:**
- Annual heating energy error (%)
- Annual cooling energy error (%)
- Monthly energy RMSE (%)
- Hourly temperature RMSE (°C)

**Test Cases:**
- Case 900 (high-mass baseline) - primary
- Case 900FF (high-mass free-floating)
- Case 960 (high-mass direct gain)
- Case 600 (low-mass baseline) - regression check

**Target:** ±15% annual energy for ASHRAE 140 compliance

### 2. Performance (25% weight)

**Metrics:**
- Single-config latency (ms)
- Population throughput (configs/sec)
- Memory usage (MB per config)
- CPU utilization (%)

**Target:** ≥1,000 configs/sec for population optimization

### 3. Implementation Complexity (15% weight)

**Metrics:**
- Lines of code added
- Algorithm complexity (1-5 scale)
- Testing burden (test count)
- Maintenance overhead

### 4. Robustness (10% weight)

**Metrics:**
- Edge case handling (extreme mass, U-value, etc.)
- Numerical stability
- Convergence reliability
- Parameter range validity

### 5. Maintainability (10% weight)

**Metrics:**
- Code clarity
- Documentation quality
- Test coverage
- Debugging ease

## Evaluation Tasks

### Task 1: Accuracy Benchmarking

**What to do:**
- Run all 5 methods on Case 900

- Rank methods by accuracy

**What to do:**

- Measure latency, throughput, memory
- Compare to 5R1C baseline
- Rank methods by performance

**Deliverable:** `docs/PERFORMANCE_COMPARISON.md`

**What to do:**
- Count lines of code per method
- Rate algorithm complexity (1-5)

**What to do:**
