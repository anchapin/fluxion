  <action>
    1. Install cargo-tarpaulin:
       ```bash
       cargo install cargo-tarpaulin
       ```

    2. Create .tarpaulin.toml configuration:
       ```toml
       [output]
       # Output formats
       Xml = true
       Html = true
       Lcov = true

       # Output directory
       out-dir = "coverage"

       [coverage]
       # Minimum coverage percentage (fail if below)
       fail-under = 80

       # Files to exclude from coverage
       exclude = [
           "tests/*",
           "benches/*",
           "examples/*",
           "tools/*",
           "api/*",
           # Generated files
           "target/*",
           # Debug-only code
           "*debug*",
       ]

       # Run tests on multiple threads
       run-types = ["Lib"]

       [report]
       # Show coverage in terminal
       show-missing-lines = true
       ```

    3. Run coverage measurement:
       ```bash
       cargo tarpaulin --lib --out xml --output-dir coverage/
       ```

    4. Parse coverage report:
       - Extract overall coverage percentage

       - List files with <50% coverage
       - Note uncovered lines in critical paths

    5. If coverage <80%:
       - Identify top 5 files with most uncovered lines
       - Determine if gaps are acceptable (debug code, error paths)
       - Document decision to accept or improve
