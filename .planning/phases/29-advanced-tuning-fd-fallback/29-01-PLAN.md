### Task 1: Implement Analytical Derivative Computation

**Effort:** 1 day
**Verification:** Derivative accuracy ±0.1% vs finite difference

**Steps:**

1.1. Add `compute_derivative_analytical()` method to `CTFCalculator`

```rust
/// Compute analytical derivative dA/ds for transmission matrix element A(s).
///
/// Uses chain rule and product rule for accurate derivative computation.
fn compute_derivative_analytical(&self, s: Complex64) -> Complex64 {
    let mut dA_ds = Complex64::new(0.0, 0.0);

    for layer in self.layers {
        let alpha = layer.diffusivity();
        let gamma = (s / alpha).sqrt();
        let gamma_l = gamma * layer.thickness;

        // d/ds[cosh(γL)] = (L/(2√(αs))) · sinh(γL)
        let d_gamma_ds = 1.0 / (2.0 * (alpha * s).sqrt());
        let d_cosh = layer.thickness * d_gamma_ds * gamma_l.sinh();

        // d/ds[sinh(γL)/(kγ)] using quotient rule
        let k_gamma = layer.conductivity * gamma;
        let d_sinh = layer.thickness * d_gamma_ds * gamma_l.cosh();
        let d_k_gamma = layer.conductivity * d_gamma_ds;

        // Quotient rule: d(u/v) = (v·du - u·dv) / v²
        let d_sinh_over_kgamma = (k_gamma * d_sinh - gamma_l.sinh() * d_k_gamma)
                                  / (k_gamma * k_gamma);

        // Transmission matrix element derivative for this layer
        dA_ds += d_cosh + d_sinh_over_kgamma;
    }

    dA_ds
}
```

1.2. Add unit test for derivative accuracy

```rust
#[test]
fn test_analytical_derivative_accuracy() {
    let layers = create_test_wall();
    let calculator = CTFCalculator::with_defaults(&layers, 3600.0);

    let s = Complex64::new(-0.001, 0.0);

    // Analytical derivative
    let dA_analytical = calculator.compute_derivative_analytical(s);

    // Finite difference derivative (reference)
    let ds = Complex64::new(1e-8, 0.0);
    let A_plus = calculator.compute_A(s + ds);
    let A_minus = calculator.compute_A(s - ds);
    let dA_fd = (A_plus - A_minus) / (2.0 * ds);

    // Verify accuracy within 0.1%
    let error = (dA_analytical - dA_fd).norm() / dA_fd.norm();
    assert!(error < 0.001, "Derivative error {:.4} exceeds 0.1%", error);
}
```

### Task 2: Replace Bisection with Newton-Raphson

**Effort:** 1 day
**Verification:** 10× speedup, same accuracy

**Steps:**

2.1. Add `find_pole_newton()` method

```rust
/// Find pole using Newton-Raphson iteration.
///
/// # Arguments
///
/// * `s_guess` - Initial guess for pole location
/// * `max_iter` - Maximum iterations (default: 50)
///
/// # Returns
///
/// Some(pole) if converged, None if failed
fn find_pole_newton(&self, s_guess: Complex64, max_iter: usize) -> Option<Complex64> {
    let mut s = s_guess;
    let tol = 1e-10;
    let max_iter = max_iter.min(50);

    for i in 0..max_iter {
        let A = self.compute_A(s);
        let dA_ds = self.compute_derivative_analytical(s);

        // Check for zero derivative
        if dA_ds.norm() < 1e-15 {
            warn!("Newton-Raphson: zero derivative at iteration {}", i);
            return None;
        }

        // Newton step: s_new = s - A(s)/A'(s)
        let delta = A / dA_ds;
        s = s - delta;

        // Check convergence
        if delta.norm() < tol {
            debug!("Newton-Raphson converged in {} iterations", i + 1);
            return Some(s);
        }

        // Check for divergence
        if s.norm() > 1e10 {
            warn!("Newton-Raphson diverging at iteration {}", i + 1);
            return None;
        }
    }

    warn!("Newton-Raphson didn't converge in {} iterations", max_iter);
    None
}
```

2.2. Modify `find_pole_bisection()` to use Newton-Raphson first

```rust
fn find_pole(&self, s_guess: f64, n: usize) -> f64 {
    let s_guess_complex = Complex64::new(s_guess, 0.0);

    // Try Newton-Raphson first (fast)
    if let Some(pole) = self.find_pole_newton(s_guess_complex, 50) {
        return pole.re;
    }

    // Fallback to bisection (slow but reliable)
    warn!("Newton-Raphson failed, falling back to bisection for pole {}", n);
    self.find_pole_bisection(s_guess, n)
}
```

### Task 3: Complex Conjugate Pairing

**Effort:** 0.5 days
**Verification:** Real-valued coefficients for multi-layer walls

**Steps:**

3.1. Add `enforce_conjugate_pairs()` method

```rust
/// Enforce complex conjugate pairing for poles.
///
/// For real-valued systems, complex poles must occur in conjugate pairs.
fn enforce_conjugate_pairs(poles: &mut Vec<Complex64>, residues: &mut Vec<Complex64>) {
    let tol = 1e-8;
    let mut i = 0;

    while i < poles.len() {
        let pole = poles[i];

        // If imaginary part is significant, find/add conjugate
        if pole.im.abs() > tol {
            let conjugate = Complex64::new(pole.re, -pole.im);

            // Check if conjugate exists nearby
            let has_conjugate = poles.iter()
                .skip(i + 1)
                .any(|&p| (p - conjugate).norm() < tol);

            if !has_conjugate {
                // Add missing conjugate with conjugated residue
                poles.insert(i + 1, conjugate);
                residues.insert(i + 1, residues[i].conj());
                i += 1;
            }
        }

        i += 1;
    }
}
```

3.2. Integrate into pole finding workflow

```rust
fn find_poles(&self) -> Vec<Complex64> {
    let mut poles = Vec::new();
    let mut residues = Vec::new();

    // Find poles...
    for n in 1..=self.max_coeffs {
        let pole = self.find_pole(n);
        poles.push(pole);
    }

    // Compute residues...
    residues = self.compute_residues(&poles);

    // Enforce conjugate pairing
    Self::enforce_conjugate_pairs(&mut poles, &mut residues);

}
```

```rust
fn test_pole_accuracy_vs_analytical() {
    // Single-layer homogeneous wall has analytical pole solution
    let layers = vec![CTFMaterial::new("Concrete", 0.2, 1.4, 2300.0, 880.0)];
    let calculator = CTFCalculator::with_defaults(&layers, 3600.0);
```
