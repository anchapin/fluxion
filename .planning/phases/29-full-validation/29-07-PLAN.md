## Goal

Benchmark performance of CTF/FD solver integration to verify throughput meets target (≥800 configs/sec). Measure both single-config latency and population throughput.

**Targets:**
- Throughput: ≥800 configs/sec (with CTF/FD for high-mass cases)
- Single-config latency: <100ms per zone
- CTF overhead: <5x vs 5R1C (target ~0.5ms/zone vs ~0.1ms/zone)
- FD overhead: <20x vs 5R1C (target ~2ms/zone vs ~0.1ms/zone)

## Tasks

### Task 1: Run Performance Benchmarks

**Command:**
```bash
cargo bench --release -- benchmark
```

**Or:**
```bash
cargo run --release -- benchmark --population 1000 --weather DEN.epw
```

**Collect:**
- Throughput (configs/sec) for 5R1C baseline
- Throughput (configs/sec) for CTF solver
- Throughput (configs/sec) for FD solver
- Single-config latency (ms per zone)
- Memory usage (MB per config)

**Test scenarios:**
1. Low-mass only (5R1C baseline)
2. High-mass only (CTF solver)
3. Mixed portfolio (50% low-mass, 50% high-mass)
4. Population sizes: 100, 1000, 10000 configs

### Task 3: Analyze Performance Bottlenecks

**Profile CTF solver:**
- Time spent in coefficient calculation (one-time cost)
- Time spent in heat flux calculation (per-timestep)
- Memory allocation overhead
- Cache efficiency

**Profile FD solver:**
- Time spent in matrix assembly
- Time spent in linear solver
- Mesh resolution impact (nodes per wall)
- Memory allocation overhead

**Optimization opportunities:**
- Precompute CTF coefficients (one-time, reuse across timesteps)
- Vectorize heat flux calculations (SIMD)
- Reduce memory allocations (reuse buffers)
- Parallelize multi-zone calculations (threading)

## Notes

**Performance Expectations:**
- 5R1C: ~0.1ms/zone, ~2,575 configs/sec (v0.6 baseline)
- CTF: ~0.5ms/zone, ~800-1,200 configs/sec (estimated)
- FD: ~2ms/zone, ~500-800 configs/sec (estimated)

**Optimization Strategy:**
1. Profile first (identify bottlenecks)
2. Optimize hot paths (heat flux calculation)
3. Reduce allocations (reuse buffers)
4. Consider SIMD (vectorize calculations)
5. Multi-threading (parallelize zones)

**If Performance Below Target:**
- Accept tradeoff if accuracy improved (±15% is priority)
- Optimize CTF coefficient precomputation
- Consider hybrid approach (5R1C for some zones, CTF for others)
- Document performance vs accuracy tradeoff
