## Goal

Validate all 600-series (low-mass) ASHRAE 140 cases to ensure no regression from v0.6 accuracy. The automatic method selection should use 5R1C for low-mass cases (τ < 2h), maintaining existing accuracy.

**Cases covered:**
- Case 600: Low-mass baseline
- Case 610: Low-mass orientation (E/W windows)
- Case 620: Low-mass windows (double clear glass)
- Case 630: Low-mass setback (thermostat schedule)
- Case 640: Low-mass shading (overhangs)
- Case 650: Low-mass ventilation (night cooling)
- Case 600FF: Low-mass free-float (no HVAC)
- Case 650FF: Low-mass free-float + ventilation

**Target:** All cases within ±15% annual energy tolerance (maintain v0.6 accuracy)
