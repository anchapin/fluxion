**Benchmarking Context:**
- Target: >1,000 configs/sec on 8-core CPU (from CLAUDE.md Performance Requirements)
- Throughput metric: configs/sec = population_size / elapsed_seconds
- Allocations metric: total heap allocations during `solve_timesteps` inner loop

**Technical Notes:**
- Use criterion for reliable microbenchmarking
- For allocation tracking, either use `dhat` crate (heap profiling) or custom `GlobalAlloc` wrapper
- Throughput test should be deterministic across runs (seeded RNG if needed)
- Target population size: 1000-5000 configs to get stable measurements
</context>
