- Allocation count: number of heap allocations per config
- Cache locality: cache-misses per million instructions (from perf)
- Regression: compare against baseline from 09-01

**Acceptance Thresholds:**
- Throughput: >= 1000 configs/sec (minimum)
- Allocation reduction: target 20-50% vs baseline (PERF-01, BUG-05)

- Mutex contention: reduced (PERF-04)

- May need minor code adjustments in batch_oracle or solve_timesteps
