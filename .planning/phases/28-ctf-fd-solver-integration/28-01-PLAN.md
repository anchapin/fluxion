### Task 3: Integrate CTF Heat Flux Calculation

**Modify:** `src/sim/engine.rs` (or wherever heat flux is calculated)

**Replace:**
```rust
// OLD: 5R1C conduction
let q_cond = (T_ext - T_int) / R_total;
```

**With:**
```rust
// NEW: CTF conduction (if enabled)
if self.ctf_enabled {
    let q_flux = self.ctf_solver.step(T_int, T_ext);
    q_flux * area  // Convert flux to power
} else {
    // Fallback to 5R1C
    (T_ext - T_int) / R_total
}
```

**Verification:**
- CTF calculation produces reasonable heat flux values
- Energy balance closes (energy_in = energy_out + mass_change)

### Task 4: Wire CTF into Timestep Loop

**Modify:** `PhysicsThermalModel::solve_timesteps()`

**Add:**
```rust
if self.ctf_enabled {
    // Update CTF solver with current temperatures
    for (i, zone) in zones.iter().enumerate() {
        let T_zone = self.inner.temperatures[i];
        let T_outdoor = self.weather.get_temp(timestep);

        // Update CTF solver boundary conditions
        self.ctf_solvers[i].update_bc(T_zone, T_outdoor);

        // Calculate conduction flux
        let q_flux = self.ctf_solvers[i].step();

        // Apply to zone energy balance
        zone.add_conduction_flux(q_flux * area);
    }
}
```

**Verification:**
- CTF solver updates at each timestep
- Zone temperatures evolve correctly

## Notes

**CTF Algorithm:**
```
q''_int,t = -Z₀·T_int,t + Σ(X_j·T_ext,t-j) - Σ(Y_j·T_int,t-j) - Σ(Φ_j·q''_t-j)
q''_ext,t = -X₀·T_ext,t + Σ(Y_j·T_ext,t-j) - Σ(Z_j·T_int,t-j) - Σ(Φ_j·q''_t-j)
```

**Key Integration Points:**
1. Coefficient precomputation during initialization
2. Temperature history management (need T_t-1, T_t-2, ... T_t-n)
3. Flux history management (need q_t-1, q_t-2, ...)
4. Timestep synchronization (CTF expects fixed Δt)

**Potential Issues:**
- History buffer initialization (first timestep)
- Timestep mismatch (CTF expects 1 hour, model may use variable)
- Unit conversion (W/m² vs W, seconds vs hours)

**Resolution:**
- Initialize history with steady-state values
- Enforce fixed timestep for CTF (3600s default)
- Add unit conversion helpers
