## Goal

Implement automatic method selection logic that chooses between 5R1C, CTF, and FD solvers based on building thermal mass characteristics.

**Rationale:**
- 5R1C: Fast, accurate for low-mass buildings (τ < 2 hours)
- CTF: Accurate for high-mass buildings, good performance
- FD: Most robust, handles extreme constructions, slower

**Selection Strategy:**
- Calculate thermal mass time constant (τ) for each wall
- τ < 2 hours → 5R1C (low mass)
- τ ≥ 2 hours → CTF (high mass, default)
- CTF fails → FD (fallback for extreme constructions)

### Task 2: Implement Time Constant Calculation

**Add to `ThermalMethodSelector`:**

```rust
/// Calculate thermal mass time constant for a wall assembly
///
/// τ = (Σ ρ_i · c_p,i · L_i) / (h_interior + h_exterior)
///
/// Where:
/// - ρ_i = density of layer i [kg/m³]
/// - c_p,i = specific heat of layer i [J/kg·K]
/// - L_i = thickness of layer i [m]
/// - h = convective heat transfer coefficient [W/m²·K]
pub fn calculate_time_constant(&self, wall: &WallAssembly) -> f64 {
    let mut thermal_mass = 0.0;  // J/m²·K

    for layer in &wall.layers {
        let mass_per_area = layer.density * layer.thickness;  // kg/m²
        let heat_cap_per_area = mass_per_area * layer.specific_heat;  // J/m²·K
        thermal_mass += heat_cap_per_area;
    }

    let h_total = self.h_interior + self.h_exterior;  // W/m²·K
    let tau_seconds = thermal_mass / h_total;  // s
    tau_seconds / 3600.0  // Convert to hours
}
```

### Task 3: Implement Method Selection Logic

**Add to `ThermalMethodSelector`:**

```rust
/// Select appropriate thermal method for a wall assembly
pub fn select_method(&self, wall: &WallAssembly) -> ThermalMethod {
    // Check for manual override
    if let Some(method) = self.override_method {
        return method;
    }

    // Calculate time constant
    let tau = self.calculate_time_constant(wall);

    // Select method based on thermal mass
    if tau < self.threshold_hours {
        ThermalMethod::FiveR1C  // Low mass: use fast 5R1C
    } else {
        ThermalMethod::CTF  // High mass: use accurate CTF
    }
}

/// Check if CTF coefficients are valid (not NaN/Inf)
pub fn validate_ctf_coefficients(coeffs: &CTFCoefficients) -> bool {
    coeffs.x.iter().all(|&x| x.is_finite()) &&
    coeffs.y.iter().all(|&y| y.is_finite()) &&
    coeffs.z.iter().all(|&z| z.is_finite()) &&
    coeffs.phi.iter().all(|&p| p.is_finite())
}

/// Fallback logic: CTF → FD
pub fn select_with_fallback(&self, wall: &WallAssembly, coeffs: &CTFCoefficients) -> ThermalMethod {
    let method = self.select_method(wall);

    if method == ThermalMethod::CTF && !self.validate_ctf_coefficients(coeffs) {
        warn!("CTF coefficients invalid, falling back to FD");
        ThermalMethod::FiniteDifference
    } else {
        method
    }
}
```

```rust
pub struct PhysicsThermalModel {
    inner: crate::sim::engine::ThermalModel<VectorField>,
    mode: ThermalModelMode,
    method_selector: ThermalMethodSelector,
    wall_methods: Vec<ThermalMethod>,  // Per-wall method selection
    // ... existing solver fields
}

impl PhysicsThermalModel {
    /// Initialize solver methods for all walls
    pub fn initialize_solvers(&mut self, walls: &[WallAssembly]) {
        self.wall_methods = walls
            .iter()
            .map(|wall| self.method_selector.select_method(wall))
            .collect();

        // Initialize appropriate solver for each wall
        for (i, method) in self.wall_methods.iter().enumerate() {
            match method {
                ThermalMethod::FiveR1C => {
                    // Use default 5R1C (no initialization needed)
                }
                ThermalMethod::CTF => {
                    // Initialize CTF solver for this wall
                    let coeffs = CTFCalculator::compute(&walls[i].layers);
                    self.ctf_solvers[i] = Some(CTFSolver::new(coeffs));
                }
                ThermalMethod::FiniteDifference => {
                    // Initialize FD solver for this wall
                    let disc = WallDiscretization::from_layers(&walls[i].layers);
                    self.fd_solvers[i] = Some(ImplicitFDSolver::new(disc));
                }
            }
        }
    }
}
```

```rust
impl ThermalMethodSelector {
    /// Log method selection for debugging
    pub fn log_selection(&self, wall: &WallAssembly, method: ThermalMethod) {
        let tau = self.calculate_time_constant(wall);
        info!(
            "Wall '{}': τ = {:.2} h → method = {:?}",
            wall.name, tau, method
        );
    }

    /// Generate selection report
    pub fn generate_report(&self, walls: &[WallAssembly]) -> String {
        let mut report = String::new();
        report.push_str("=== Method Selection Report ===\n");

        let mut counts = [0, 0, 0];  // [5R1C, CTF, FD]
        for wall in walls {
            let method = self.select_method(wall);
            match method {
                ThermalMethod::FiveR1C => counts[0] += 1,
                ThermalMethod::CTF => counts[1] += 1,
                ThermalMethod::FiniteDifference => counts[2] += 1,
            }
        }

        report.push_str(&format!(
            "5R1C: {} walls, CTF: {} walls, FD: {} walls\n",
            counts[0], counts[1], counts[2]
        ));

        report
    }
}
```

## Notes

**Time Constant Formula:**
```
τ = (Σ ρ_i · c_p,i · L_i) / (h_interior + h_exterior)
```

**Typical Values:**
- Wood frame wall: τ ≈ 0.5-1.5 hours → 5R1C
- Concrete wall (200mm): τ ≈ 3-5 hours → CTF
- Adobe wall (300mm): τ ≈ 8-12 hours → CTF/FD

**Threshold Sensitivity:**
- Default: 2.0 hours (ISO 13790 guidance)
- Range: 1.5-3.0 hours (user configurable)
- Impact: More 5R1C = faster, less accurate; More CTF = slower, more accurate

**Fallback Triggers:**
- CTF coefficients are NaN or Inf
- CTF solver fails to converge
- Wall construction too complex for CTF
