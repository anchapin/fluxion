### Task 4: Wire FD into Timestep Loop

**Modify:** `PhysicsThermalModel::solve_timesteps()`

**Add:**
```rust
if self.fd_enabled {
    for (i, zone) in zones.iter().enumerate() {
        let T_zone = self.inner.temperatures[i];
        let T_outdoor = self.weather.get_temp(timestep);
        let solar_flux = self.weather.get_solar(timestep);

        // Create boundary conditions
        let interior_bc = SurfaceBC::new_interior(h_interior, T_zone);
        let exterior_bc = SurfaceBC::new_exterior(h_exterior, T_outdoor, solar_flux);

        // Advance FD solver
        self.fd_solvers[i].step(timestep_seconds, &interior_bc, &exterior_bc);

        // Get surface heat flux
        let q_flux = self.fd_solvers[i].surface_flux();

        // Apply to zone energy balance
        zone.add_conduction_flux(q_flux * area);
    }
}
```

### Task 5: Add FD Stability Checks

**Add validation:**

impl ImplicitFDSolver {
    /// Check if timestep is stable for given discretization
    pub fn check_stability(&self) -> Result<(), SolverError> {
        let fo_max = 0.5;  // Stability limit for explicit (not needed for implicit)
        let fo = self.alpha * self.dt / (self.dx * self.dx);

        // Implicit BTCS is unconditionally stable, but warn if Fo > 10
        if fo > 10.0 {
            warn!("Fourier number {} is very high - accuracy may suffer", fo);
        }

        Ok(())
    }
}

## Notes

**FD Algorithm (Implicit BTCS):**
```
-Fo·T_{i-1}^{n+1} + (1+2Fo)·T_i^{n+1} - Fo·T_{i+1}^{n+1} = T_i^n
```

Solved using Thomas algorithm (TDMA) in O(n) operations.

**Key Integration Points:**
1. Discretization from wall constructions (nodes per layer)
2. Boundary condition application (Robin BC for convection)
3. Surface flux extraction from temperature profile
4. Timestep synchronization

**Potential Issues:**
- Discretization too coarse (accuracy loss)
- Discretization too fine (performance loss)
- Multi-layer walls (material property jumps)

**Resolution:**
- Default: 10 nodes per layer (balance accuracy/performance)
- Use harmonic mean for conductivity at material interfaces
- Allow user configuration for special cases
