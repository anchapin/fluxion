# Existing Implementation from Plan 18-09

From 18-09-SUMMARY.md, the HVAC energy accumulation was fixed in simulate_case_with_diagnostics():

```rust
// Fixed in 18-09: Changed immutable let to mutable let mut and added accumulation
if hvac_kwh > 0.0 {
    annual_heating_joules += hvac_kwh * 3.6e6;
} else {
    annual_cooling_joules += (-hvac_kwh) * 3.6e6;
}
```

However, this fix has a **critical bug**: `step_physics()` returns **Watts** (instantaneous power in W), not kWh (energy).

The correct unit conversion should be:
- **Wrong:** `hvac_kwh * 3.6e6` (assumes kWh, converts to Joules by multiplying by 3.6e6 J/kWh)
- **Correct:** `hvac_kwh * 3600.0` (Watts × seconds = Joules, where dt = 3600s for hourly timesteps)

This explains why CLI shows 0.00 MWh cooling while test shows 65,642 kWh:
- The unit mismatch causes values 1000x too large
- Sign handling fails for cooling (negative values)
- Result: cooling energy accumulates to 0.00 MWh instead of 6-10 MWh
