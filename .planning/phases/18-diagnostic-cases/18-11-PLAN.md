```rust
// Accumulate electrical energy consumption (Plan 18-08)
// actual_electrical_power is in Watts, dt is in seconds
// Convert to kWh: (Watts × dt) / 3.6e6 = kWh
let dt = 3600.0; // Timestep in seconds (1 hour)
self.annual_electrical_energy += actual_electrical_power * dt / 3.6e6;
```

This looks mathematically correct (Watts × seconds / 3.6e6 = kWh), but the result is 4 orders of magnitude too low.

**File: src/sim/hvac/equipment.rs (lines 555-563)**
```rust
fn calculate_power(&self, load: f64, outdoor_temp: f64, mode: HVACMode) -> f64 {
    let efficiency = self.calculate_efficiency(load / self.rated_capacity(), outdoor_temp, mode);
    if efficiency > 0.0 {
        load / efficiency
    } else {
        0.0
    }
}
```

This returns electrical power in Watts (thermal_load / COP), which should be correct.
