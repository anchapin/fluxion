# Plan 24-05: Time Constant and Timestep Sensitivity Analysis

**Type:** `auto`
**Wave:** 2 — Component Testing
**Depends on:** 24-01, 24-02 (spec verification and audit)

---

## Goal

Analyze time constants for 6R2C thermal mass nodes and determine if the 1-hour timestep is appropriate. Test sensitivity to timestep variations.

---

**Deliverable:** Test file with module structure

### 2. Test Time Constant Calculation Formulas

**What:** Verify time constant formulas for both capacitance nodes.

**Actions:**
- Verify formula for τ_s (surface node):
  - τ_s = C_s / (h_tr_es + h_tr_is + h_tr_ms)
  - Units: J/K ÷ W/K = seconds
- Verify formula for τ_m (mass node):
  - τ_m = C_m / (h_tr_em + h_tr_wm + h_tr_ms)
  - Units: J/K ÷ W/K = seconds
- Test with known values:
  - C_m = 19,944,509 J/K (Case 900)
  - Sum of conductances ≈ 1150 W/K
  - Expected τ_m ≈ 19,944,509 / 1150 ≈ 17,343 s ≈ 4.82 hours
- Verify conversion between seconds and hours

**Deliverable:** 4-5 time constant formula tests

---

### 3. Analyze Case 900 Time Constants

**What:** Calculate and document time constants for Case 900.

**Actions:**
- Extract Case 900 parameters:
  - C_m = 19,944,509 J/K (from test or config)
  - C_s = ? (calculate from surface mass)
  - All conductances (from conductance tests)
- Calculate τ_m and τ_s
- Compare against timestep (1 hour = 3600 s)
- Assess numerical integration quality:
  - Rule of thumb: timestep should be < τ/10 for good accuracy
  - For τ_m = 4.82 hours, timestep should be < 0.48 hours = 29 minutes
  - Current 1-hour timestep may be too coarse!

**Deliverable:** Time constant analysis report with recommendations

---

### 4. Test Timestep Sensitivity

**What:** Measure accuracy vs timestep for 6R2C.

**Actions:**
- Run Case 900 with varying timesteps:
  - Δt = 1 hour (baseline)
  - Δt = 30 minutes (2× more steps)
  - Δt = 15 minutes (4× more steps)
  - Δt = 6 minutes (10× more steps)
  - Δt = 1 minute (60× more steps)
- Compare annual energy results:
  - Heating energy vs timestep
  - Cooling energy vs timestep
  - Peak loads vs timestep
- Plot convergence: does energy converge as Δt → 0?

**Deliverable:** Timestep sensitivity analysis (table + plot data)

---

### 5. Test Numerical Stability

**What:** Verify integration method is stable for all timesteps.

**Actions:**
- Identify integration method (explicit Euler, implicit, etc.)
- Check stability criteria:
  - Explicit Euler: Δt < 2τ for stability
  - For τ_m = 4.82 hours, Δt must be < 9.64 hours
  - 1-hour timestep should be stable, but verify
- Test with extreme timesteps:
  - Δt = 10 hours (should be unstable or oscillatory)
  - Δt = 24 hours (definitely unstable for explicit)
- Check for:
  - Temperature oscillations
  - Energy non-conservation
  - NaN or Inf values

**Deliverable:** Stability analysis report

---

### 6. Test Sub-Step Integration

**What:** Implement and test sub-stepping for better accuracy.

**Actions:**
- Add optional sub-stepping to 6R2C integrator:
  - For each 1-hour timestep, take N sub-steps
  - Example: 6 sub-steps of 10 minutes each
- Test with Case 900:
  - Compare 1-hour single step vs 6 × 10-min sub-steps
  - Measure accuracy improvement
  - Measure performance cost
- Determine optimal sub-stepping:
  - How many sub-steps needed for <5% error?
  - Is performance cost acceptable?

**Deliverable:** Sub-stepping implementation + test results

---

### 7. Compare 5R1C vs 6R2C Time Constants

**What:** Analyze why 6R2C shows no improvement despite more nodes.

**Actions:**
- Calculate 5R1C time constant (single C node)
- Calculate 6R2C time constants (two C nodes)
- Compare:
  - Are time constants similar?
  - Does 6R2C capture additional dynamics?
  - Is the limiting factor the timestep or the network structure?
- Hypothesis testing:
  - If τ_5R1C ≈ τ_6R2C, adding nodes doesn't help
  - If timestep too coarse, both 5R1C and 6R2C suffer equally
  - If structure limited, finer timestep won't help

**Deliverable:** Comparative analysis report

---

### 8. Document Timestep Recommendations

**What:** Provide clear guidance on appropriate timestep.

**Actions:**
- Based on analysis, recommend timestep for:
  - Low-mass buildings (τ < 2 hours)
  - Medium-mass buildings (τ = 2-6 hours)
  - High-mass buildings (τ > 6 hours)
- Recommend sub-stepping strategy if needed
- Document performance vs accuracy trade-off
- Update configuration defaults if needed
