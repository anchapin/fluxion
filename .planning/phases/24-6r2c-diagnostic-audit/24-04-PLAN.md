# Plan 24-04: Node Placement and Boundary Condition Tests

**Type:** `auto`
**Wave:** 2 — Component Testing
**Depends on:** 24-01, 24-02 (spec verification and audit)

---

## Goal

Verify that thermal mass nodes are positioned correctly (surface vs core temperature) and boundary conditions are applied according to ISO 13790 specification.

---

## Tasks

### 1. Create Test File Structure

**What:** Add dedicated test file for node placement verification.

**Actions:**
- Create `tests/6r2c_node_placement_tests.rs` (new dedicated file)
- Add module structure:
  ```rust
  mod test_mass_node_position;      // where is C_m located?
  mod test_surface_node_position;    // where is C_s located?
  mod test_boundary_conditions;      // interior/exterior BCs
  mod test_initial_conditions;       // starting temperatures
  mod test_solar_gain_distribution;  // which node gets solar?
  mod test_internal_gain_distribution; // convective/radiative split
  ```

**Deliverable:** Test file with module structure

---

### 2. Test Mass Node Position (C_m)

**What:** Verify thermal mass node represents correct physical location.

**Actions:**
- **Question to answer:** Does C_m represent:
  - Surface temperature (T_surface)?
  - Core temperature (T_core)?
  - Average temperature (T_avg)?
  - Effective temperature (T_effective)?
- Create synthetic test case:
  - Multi-layer wall with known properties
  - Apply step change in exterior temperature
  - Track C_m temperature response
  - Compare against analytical solution for surface/core/avg
- Verify against ISO 13790 specification

**Deliverable:** 3-4 tests proving what C_m represents physically

---

### 3. Test Surface Node Position (C_s)

**What:** Verify surface node represents correct physical location.

**Actions:**
- **Question to answer:** Does C_s represent:
  - Interior surface temperature?
  - Exterior surface temperature?
  - Weighted average?
- Create synthetic test case:
  - Wall with surface mass layer
  - Apply solar radiation step input
  - Track C_s temperature response
  - Verify response time matches expected surface behavior
- Verify against ISO 13790 specification

**Deliverable:** 3-4 tests proving what C_s represents physically

---

### 4. Test Boundary Conditions

**What:** Verify interior and exterior boundary conditions applied correctly.

**Actions:**
- **Exterior boundary (T_e):**
  - Verify T_e = T_outdoor + solar-air temperature correction
  - Test with known outdoor temperature and solar radiation
  - Verify sol-air temperature formula: T_sol-air = T_out + (α × I_sol / h_se)
- **Interior boundary (T_i):**
  - Verify T_i = indoor setpoint (or free-floating)
  - Test with HVAC on/off scenarios
  - Verify internal gains affect T_i correctly
- **Test edge cases:**
  - Adiabatic walls (no exterior boundary)
  - Inter-zone walls (both sides conditioned)
  - Ground contact floors (T_ground boundary)

**Deliverable:** 6-8 boundary condition tests

---

### 5. Test Initial Conditions

**What:** Verify capacitance nodes start at correct temperatures.

**Actions:**
- Test default initialization:
  - C_m starts at T_initial (typically 20°C or T_outdoor?)
  - C_s starts at T_initial
- Test warm-start from previous simulation:
  - Save final state, reload as initial state
  - Verify continuity (no temperature jumps)
- Test steady-state initialization:
  - Calculate steady-state temperatures before simulation
  - Verify no transient spike at t=0

**Deliverable:** 4-5 initial condition tests

---

### 6. Test Solar Gain Distribution

**What:** Verify solar radiation is distributed to correct nodes.

**Actions:**
- **Question to answer:** Which node(s) receive solar gain?
  - C_s (surface node)?
  - C_m (mass node)?
  - Both (split by absorption depth)?
- Create test case:
  - Wall with known solar absorptance
  - Apply known solar radiation (e.g., 500 W/m²)
  - Track which node temperature increases
  - Verify split ratio matches ISO 13790
- Test shortwave vs longwave radiation separately

**Deliverable:** 4-5 solar distribution tests

---

### 7. Test Internal Gain Distribution

**What:** Verify internal gains (people, equipment, lighting) are split correctly.

**Actions:**
- **Convective vs Radiative split:**
  - Convective fraction → air node (immediate)
  - Radiative fraction → surface/mass nodes (absorbed over time)
- Test with known internal gain (e.g., 1000 W)
- Verify split ratio (typically 60% convective, 40% radiative?)
- Track radiative fraction absorption by C_s and C_m
- Verify time delay in radiative fraction effect

**Deliverable:** 4-5 internal gain distribution tests

---

### 8. Test Multi-Zone Node Coupling

**What:** Verify inter-zone heat transfer couples nodes correctly.

**Actions:**
- Create two-zone test case (like Case 960):
  - Zone 0: conditioned
  - Zone 1: unconditioned (sunspace)
  - Common wall with thermal mass
- Verify heat flow through common wall:
  - Q = U × A × (T_zone0 - T_zone1)
  - Affects both zone temperatures
  - Affects common wall mass node
- Test with door opening (direct air exchange)

**Deliverable:** 4-5 multi-zone coupling tests
