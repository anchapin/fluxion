# Plan 24-03: Conductance Calculation Unit Tests

**Type:** `auto`
**Wave:** 2 — Component Testing
**Depends on:** 24-01, 24-02 (spec verification and audit)

---

## Goal

Create comprehensive unit tests for every conductance calculation in the 6R2C network. Each test verifies one calculation with known inputs/outputs.

---

## Tasks

### 1. Create Test File Structure

**What:** Add dedicated test file for 6R2C conductance tests.

**Actions:**
- Create `tests/6r2c_conductance_tests.rs` (new dedicated file)
- Add module structure:
  ```rust
  mod test_h_tr_em;  // exterior-to-mass conductance
  mod test_h_tr_ms;  // mass-to-surface conductance
  mod test_h_tr_wm;  // wall-to-mass conductance
  mod test_h_tr_is;  // interior-surface conductance
  mod test_h_tr_es;  // exterior-surface conductance
  mod test_h_vent;   // ventilation conductance
  mod test_coupling_ratios;  // coupling ratio calculations
  ```
- Ensure tests integrate with existing test harness

**Deliverable:** Test file with module structure

---

### 2. Test h_tr_em (Exterior-to-Mass Conductance)

**What:** Verify exterior-to-mass heat transfer conductance.

**Actions:**
- Test Case 900 parameters:
  - Wall construction: heavy mass (concrete/brick)
  - Expected h_tr_em ≈ 57.42 W/K (from KNOWN_LIMITATIONS.md)
- Test edge cases:
  - Zero mass wall (h_tr_em should be 0)
  - Infinite mass wall (h_tr_em should approach limit)
  - Single-layer wall
  - Multi-layer wall
- Verify formula: h_tr_em = f(A_wall, U_value, mass_properties)

**Deliverable:** 5-7 passing unit tests for h_tr_em

---

### 3. Test h_tr_ms (Mass-to-Surface Conductance)

**What:** Verify mass-to-surface heat transfer conductance.

**Actions:**
- Test Case 900 parameters:
  - Expected h_tr_ms ≈ 1087.5 W/K (from KNOWN_LIMITATIONS.md)
- Test edge cases:
  - Zero mass (h_tr_ms should be 0)
  - Surface-only mass (no internal mass)
  - Internal-only mass (no surface mass)
- Verify coupling ratio: h_tr_em / h_tr_ms ≈ 0.0525 for Case 900

**Deliverable:** 5-7 passing unit tests for h_tr_ms

---

### 4. Test h_tr_wm (Wall-to-Mass Conductance)

**What:** Verify wall-to-mass heat transfer conductance.

**Actions:**
- Test with known wall constructions
- Test edge cases:
  - No internal mass
  - Mass at surface vs mass at core
- Verify formula matches ISO 13790

**Deliverable:** 3-5 passing unit tests for h_tr_wm

---

### 5. Test h_tr_is and h_tr_es (Surface Conductances)

**What:** Verify interior and exterior surface conductances.

**Actions:**
- Test h_tr_is (interior surface):
  - Standard value: ~3.45 W/(m²·K) × area
  - Test with different surface areas
- Test h_tr_es (exterior surface):
  - Standard value: ~25 W/(m²·K) × area
  - Test with different surface areas
- Verify convection + radiation combined correctly

**Deliverable:** 4-6 passing unit tests for surface conductances

---

### 6. Test h_vent (Ventilation Conductance)

**What:** Verify ventilation heat transfer conductance.

**Actions:**
- Test formula: h_vent = ρ_air × c_p_air × V_dot (W/K)
- Test with known airflow rates
- Test edge cases:
  - Zero ventilation (h_vent = 0)
  - Natural infiltration only
  - Mechanical ventilation
- Verify unit conversions (m³/h → m³/s)

**Deliverable:** 3-5 passing unit tests for ventilation

---

### 7. Test Coupling Ratio Calculations

**What:** Verify coupling ratio between mass nodes and surfaces.

**Actions:**
- Test Case 900: coupling_ratio = h_tr_em / h_tr_ms ≈ 0.0525
- Test with varying mass distributions
- Verify coupling ratio interpretation:
  - Low ratio (<0.1): mass mostly coupled to interior
  - High ratio (>0.5): mass mostly coupled to exterior
- Document implications for high-mass buildings

**Deliverable:** 3-4 passing unit tests + documentation

---

### 8. Add Property-Based Tests

**What:** Use proptests to verify conductance invariants.

**Actions:**
- Add `proptest` dependencies if not present
- Create property tests:
  - All conductances must be non-negative
  - Conductance scales linearly with area
  - Conductance scales with mass (up to saturation)
  - Coupling ratio always between 0 and 1
- Run with `cargo test -- --ignored` for extended tests

**Deliverable:** 4-6 property-based tests

## Notes

- Tests should be independent (no shared state)
- Use `#[test]` for unit tests, `#[test] #[ignore]` for slow proptests
- Include expected values in test names for clarity
- If any test fails, this is a **critical bug** — document immediately
