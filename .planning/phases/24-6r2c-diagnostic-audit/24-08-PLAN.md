# Plan 24-08: EnergyPlus Installation and Test Case Setup

**Type:** `auto`
**Wave:** 4 — Reference Comparison

## Goal

Install EnergyPlus on the local system and create IDF (Input Data File) test cases that match Fluxion's ASHRAE 140 cases exactly. Enable direct apples-to-apples comparison.

---

## Tasks

### 1. Install EnergyPlus

**What:** Install EnergyPlus v23.2 (or latest stable) on the system.

**Actions:**
- Check system architecture: `uname -m` (x86_64, aarch64?)
- Check OS version: `cat /etc/os-release` (Ubuntu, Debian, etc.)
- Install via package manager or direct download:
  ```bash
  # Option 1: NREL repository (Ubuntu/Debian)
  sudo apt update
  sudo apt install energyplus

  # Option 2: Download from GitHub releases
  wget https://github.com/NREL/EnergyPlus/releases/download/v23.2.0/EnergyPlus-23.2.0-Linux-Ubuntu2004-x86_64.deb
  sudo dpkg -i EnergyPlus-23.2.0-Linux-Ubuntu2004-x86_64.deb
  ```
- Verify installation:
  ```bash
  energyplus --version
  which energyplus
  ```
- Locate EnergyPlus directories:
  - Executable: `/usr/local/bin/energyplus` or `/usr/bin/energyplus`
  - Weather files: `/usr/local/share/energyplus/weather/`
  - Example files: `/usr/local/share/energyplus/ExampleFiles/`

**Deliverable:** EnergyPlus installed and verified

---

### 2. Create Case 600 IDF (Low-Mass Baseline)

**What:** Create EnergyPlus IDF file for Case 600 that matches Fluxion inputs exactly.

**Actions:**
- Read Fluxion Case 600 configuration:
  - Building geometry (dimensions, orientation)
  - Construction (wall layers, U-values, mass)
  - Window properties (SHGC, U-value)
  - Internal loads (people, equipment, lighting)
  - HVAC system (ideal loads, setpoints)
  - Schedules (occupancy, thermostat)
- Create IDF file using EnergyPlus syntax:
  - Use `BuildingSurface:Detailed` for walls, roof, floor
  - Use `Construction` with `Material` layers matching Case 600
  - Use `Window` objects with correct properties
  - Use `ZoneHVAC:IdealLoadsAirSystem` for ideal HVAC
  - Use `Schedule:Compact` for occupancy and thermostat
- Match weather file (ASHRAE 140 uses specific weather year)
- Validate IDF with EnergyPlus:
  ```bash
  energyplus --input-file Case600.idf --weather-file ASHRAE140.epw --output-dir output_600
  ```

**Deliverable:** `Case600.idf` + `Case600.epw` + simulation output

---

### 3. Create Case 900 IDF (High-Mass Problem)

**What:** Create EnergyPlus IDF file for Case 900 with high-mass construction.

**Actions:**
- Read Fluxion Case 900 configuration:
  - Same geometry as Case 600
  - Different construction (heavy mass: concrete/brick)
  - Higher thermal capacitance
- Create IDF file:
  - Modify `Material` layers for high-mass construction
  - Ensure thermal mass properties (density, specific heat) match Case 900
  - Keep all other inputs identical to Case 600
- Run simulation:
  ```bash
  energyplus --input-file Case900.idf --weather-file ASHRAE140.epw --output-dir output_900
  ```
- Verify output:
  - Annual heating energy should be ~1.17-2.04 MWh (ASHRAE 140 reference range)
  - Annual cooling energy should be ~2.13-3.67 MWh

**Deliverable:** `Case900.idf` + simulation output

### 4. Extract EnergyPlus Internal State Variables

**What:** Configure EnergyPlus to output internal temperatures and heat flows.

**Actions:**
- Add `Output:Variable` objects to IDF:
  ```idf
  Output:Variable,*,Zone Air Temperature,hourly;  !- T_interior
  Output:Variable,*,Surface Inside Face Temperature,hourly;  !- T_surface
  Output:Variable,*,Surface Average Temperature,hourly;  !- T_avg (compare to T_mass)
  Output:Variable,*,Zone Ideal Loads Supply Air Total Heating Energy,hourly;  !- Q_HVAC
  Output:Variable,*,Surface Convection Heat Gain,hourly;  !- Q_convective
  Output:Variable,*,Surface Net Longwave Radiation Heat Gain,hourly;  !- Q_radiative
  ```
- Add `Output:Meter` for energy totals:
  ```idf
  Output:Meter,Heating:EnergyTransfer,hourly;
  Output:Meter,Cooling:EnergyTransfer,hourly;
  ```
- Request CSV output format for easy analysis
- Re-run simulations with output variables enabled

**Deliverable:** EnergyPlus CSV output with internal states

### 5. Create Comparison Script

**What:** Python script to compare Fluxion vs EnergyPlus outputs.

**Actions:**
- Create `tools/compare_fluxion_energyplus.py`:
  ```python
  import pandas as pd
  import matplotlib.pyplot as plt

  # Load Fluxion output
  fluxion = pd.read_csv('output_fluxion/case900_trace.csv')

  # Load EnergyPlus output
  energyplus = pd.read_csv('output_900/eplusout.csv')

  # Compare annual energy
  print(f"Fluxion heating: {fluxion['hvac_heating'].sum() / 1e6:.2f} MWh")
  print(f"EnergyPlus heating: {energyplus['Heating'].sum() / 1e6:.2f} MWh")

  # Plot time-series
  plt.figure(figsize=(12, 6))
  plt.plot(fluxion['T_interior'], label='Fluxion')
  plt.plot(energyplus['Zone Air Temperature'], label='EnergyPlus', alpha=0.7)
  plt.legend()
  plt.savefig('comparison_T_interior.png')
  ```
- Compare key metrics:
  - Annual heating/cooling energy
  - Peak loads
  - Hourly temperatures (MAE, RMSE)
  - Heat flows (where comparable)

**Deliverable:** Comparison script + sample output

## Notes

- EnergyPlus is the **reference implementation** — its results are considered "ground truth"
- Matching inputs exactly is critical — small differences can cause large output variations
- EnergyPlus uses CTF (Conduction Transfer Functions), not RC networks — this is the key difference we're investigating
- If EnergyPlus gets Case 900 right with same inputs, RC networks are fundamentally limited
