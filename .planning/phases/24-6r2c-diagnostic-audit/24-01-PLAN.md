# Plan 24-01: ISO 13790 6R2C Equation Verification

**Type:** `auto`
**Wave:** 1 — Specification Audit
**Depends on:** Nothing (starting point)

---

## Goal

Re-derive and verify all 6R2C thermal network equations from ISO 13790 Annex C specification. Create a reference document that serves as the ground truth for all subsequent audits.

---

## Tasks

### 1. Extract ISO 13790 Annex C 6R2C Specification

**What:** Create a comprehensive reference document with all 6R2C equations.

**Actions:**
- Read existing `docs/ASHRAE_13790_5R1C_MODEL.md` for 5R1C baseline
- Create `docs/ISO_13790_6R2C_SPECIFICATION.md` with:
  - Network topology diagram (ASCII or description)
  - All 6 resistances defined with formulas
  - Both capacitance nodes defined (surface mass + internal mass)
  - Heat balance equations for each node
  - Conductance formulas (h_tr_em, h_tr_ms, h_tr_wm, etc.)
  - Boundary conditions (interior/exterior)
  - Initial conditions for capacitance nodes

**Reference:** ISO 13790:2007 Annex C (multi-zone method with thermal mass)

---

### 2. Verify Thermal Resistance Calculations

**What:** Check each resistance calculation from first principles.

**Actions:**
- R_em (exterior-to-mass): Verify formula, units, typical values
- R_ms (mass-to-surface): Verify formula, units, typical values
- R_wm (wall-to-mass): Verify formula, units, typical values
- R_si (surface-to-interior): Verify formula, units, typical values
- R_se (exterior-to-surface): Verify formula, units, typical values
- R_vent (ventilation resistance): Verify formula, units, typical values

**Deliverable:** Table comparing ISO 13790 formulas vs Fluxion implementation

---

### 3. Verify Thermal Capacitance Calculations

**What:** Check both capacitance node calculations.

**Actions:**
- C_m (internal thermal mass): Verify formula, units, typical values
- C_s (surface thermal mass): Verify formula, units, typical values
- Check effective mass fraction calculations (which materials contribute)
- Verify unit conversions (J/kg·K → kWh/K, kg → m³ via density)

**Deliverable:** Capacitance calculation verification table

---

### 4. Verify Heat Balance Equations

**What:** Derive and verify the differential equations for each node.

**Actions:**
- Surface node heat balance: dT_s/dt = f(T_e, T_m, T_i, Q_solar, Q_internal)
- Mass node heat balance: dT_m/dt = f(T_s, T_i, T_e, Q_internal_mass)
- Check sign conventions (heat gain positive, loss negative)
- Check coupling terms between nodes

**Deliverable:** Verified heat balance equations with step-by-step derivation

---

### 5. Verify Time Constant Formulas

**What:** Check time constant calculations for both capacitance nodes.

**Actions:**
- τ_s (surface time constant): τ_s = C_s / (sum of conductances)
- τ_m (mass time constant): τ_m = C_m / (sum of conductances)
- Verify against Case 900 parameters (C_m = 19,944,509 J/K)
- Check if timestep (1 hour) is appropriate for calculated time constants

**Deliverable:** Time constant analysis with recommendations

---

## Verification Criteria

**Plan succeeds when:**
1. ✅ `docs/ISO_13790_6R2C_SPECIFICATION.md` created with complete equations
2. ✅ All 6 resistances verified against ISO 13790 Annex C
3. ✅ Both capacitances verified with unit analysis
4. ✅ Heat balance equations derived and verified
5. ✅ Time constant formulas verified with Case 900 parameters
6. ✅ Any discrepancies between ISO 13790 and Fluxion documented
