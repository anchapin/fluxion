# Plan 24-06: Heat Flow Path Tracing Instrumentation

**Type:** `auto`
**Wave:** 3 — Integration Tracing
**Depends on:** 24-03, 24-04, 24-05 (component tests passing)

## Goal

Add instrumentation to trace heat flow through every branch of the 6R2C network at each timestep. Export detailed data for analysis to identify where 5R1C and 6R2C diverge.

---

## Tasks

### 1. Design Tracing Instrumentation

**What:** Plan what data to capture and how to export it.

**Actions:**
- Identify all heat flow paths to instrument:
  - Q_exterior→surface (through h_tr_es)
  - Q_surface→interior (through h_tr_is)
  - Q_surface→mass (through h_tr_ms)
  - Q_exterior→mass (through h_tr_em)
  - Q_mass→wall (through h_tr_wm)
  - Q_ventilation (through h_vent)
  - Q_solar (absorbed at which nodes?)
  - Q_internal (convective and radiative fractions)
- Decide data format:
  - CSV for time-series analysis
  - JSON for configuration metadata
  - One file per simulation run
- Decide sampling rate:
  - Every timestep (8760 rows for annual)
  - Hourly aggregates (same for hourly timestep)
  - Daily aggregates (365 rows, easier to analyze)

**Deliverable:** Instrumentation design document

### 6. Energy Balance Verification

**What:** Verify energy conservation at each node.

**Actions:**
- For each timestep, verify:
  - Surface node: Q_in - Q_out = C_s × dT_s/dt
  - Mass node: Q_in - Q_out = C_m × dT_m/dt
  - Air node: Q_in - Q_out + Q_HVAC = 0 (steady-state)
- Calculate energy balance error:
  - Should be < 0.01% for correct implementation
  - Large error indicates bug in heat balance
- Track cumulative error over simulation

**Deliverable:** Energy balance verification report

---

### 7. Identify Divergence Root Cause

**What:** Pinpoint where/why 5R1C and 6R2C produce different results.

**Actions:**
- Compare annual energy totals:
  - 5R1C heating: 5.35 MWh (Case 900)
  - 6R2C heating: 5.35 MWh (Case 900, same?)
- If identical:
  - Root cause: 6R2C not adding new dynamics (structural issue)
  - Investigate coupling terms (h_tr_em, h_tr_ms)
  - Check if mass node is "invisible" to heat flow
- If different but both wrong:
  - Root cause: both have same fundamental limitation
  - Investigate network topology
- If 6R2C different but still wrong:
  - Root cause: 6R2C captures different physics, but not the right physics
  - Investigate what physics reference programs use

**Deliverable:** Root cause hypothesis with evidence
