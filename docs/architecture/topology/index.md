## How to regenerate

```bash
cargo build -p fluxion   # debug build is what the drift gate uses
python3 scripts/generate_topology_diagrams.py
python3 scripts/check_topology_drift.py   # must exit 0 before you commit
```

The drift gate (`scripts/check_topology_drift.py`, wired into `.github/workflows/topology_visualizer.yml`) regenerates everything into a temp directory and byte-compares it against the committed tree; any physics change that alters the topology graph requires regenerating and committing these artifacts in the same PR.
