# ASHRAE 140 Compliance Documentation

This directory contains the documentation required for a formal ASHRAE 140 compliance submission. It is a **work in progress** — sections marked `[STUB]` require content from the engineering team before a submission can be made.

## Submission Checklist

| Document | File | Status |
|----------|------|--------|
| Software Qualification Test (SQT) report | `SQT-report.md` | 🔴 Stub — needs engineering input |
| Standards version declaration | `ashrae140-version.md` | 🟡 Partial — version identified, needs formal statement |

| Section 8 output reporting compliance | `section8-output-gaps.md` | 🔴 Gaps documented, fixes in progress |
| Standards roadmap (future certifications) | `standards-roadmap.md` | ✅ Initial draft complete |

## Current Certification Status

**fluxion v0.8.0 is NOT ready for an ASHRAE 140 compliance submission.**

Known blockers:
- Pass rate is approximately 36% across all test cases (see deviations register)
- Peak load outputs significantly overestimated (CTF solver limitation — v1.0 fix planned)
- Section 8 output format gaps not yet closed (tracked in issue #749)
- SQT report, weather file provenance, and deviations register are incomplete
- Inter-program comparison charts are stubs

Target: Full compliance submission readiness is planned for **v1.0** once the finite volume solver and physics Wave fixes (Waves 1–5) are complete.
