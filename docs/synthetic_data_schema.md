# Synthetic Training Data Schema v2.1

> Schema for synthetic training data generated for Phase 4 surrogate model training.

## Overview

This schema defines the structure and validation rules for synthetic training datasets generated by the v2.1 pipeline (`scripts/generate_training_data.py`). The data is used to train neural network surrogates for building energy simulation.

**Prerequisite**: Phase 1 (v1.3) must achieve ≥80% ASHRAE 140 blind validation pass rate before this data is used for production surrogate models.

---

## Schema Version

Current version: **2.1.0**

## Dataset Components

### 1. Zone Thermal Dataset

Training data for the zone thermal solver (6R2C thermal network).

**File**: `zone_thermal/train.parquet`, `zone_thermal/val.parquet`, `zone_thermal/test.parquet`

| Column | Type | Unit | Description | Range |
|--------|------|------|-------------|-------|
| `scenario_id` | string | - | Unique scenario identifier | `scenario_00000` - `scenario_09999` |
| `timestep` | int | - | Timestep index | 0 - 8759 |
| `exterior_temp` | float | °C | Outdoor air temperature | -50 to 60 |
| `zone_temp` | float | °C | Zone air temperature | 10 to 45 |
| `solar_rad` | float | W/m² | Solar radiation on zone | 0 to 1200 |
| `humidity` | float | % | Relative humidity | 0 to 100 |
| `occupancy` | float | fraction | Occupancy fraction | 0.0 to 1.0 |
| `climate_zone` | string | - | ASHRAE climate zone | `1A`, `2A`, `3A`, `4A`, `5A`, `6A`, `7`, `8` |
| `hour_of_day` | int | - | Hour of day | 0 to 23 |
| `day_of_year` | int | - | Day of year | 1 to 365 |
| `hvac_mode` | string | - | HVAC operating mode | `heating`, `cooling`, `off` |
| `zone_area_m2` | float | m² | Zone floor area | 20 to 500 |
| `zone_volume_m3` | float | m³ | Zone volume | 54 to 1350 |
| `window_ratio` | float | fraction | Window-to-wall ratio | 0.1 to 0.5 |
| `wall_u_value` | float | W/m²K | Wall U-value | 0.2 to 2.0 |
| `thermal_mass_mj_k` | float | MJ/K | Effective thermal mass | 1.0 to 100.0 |
| **`zone_temp_next`** | float | °C | **TARGET**: Next timestep zone temp | -50 to 60 |
| **`hvac_power`** | float | W | **TARGET**: HVAC power (heating+/cooling-) | -50000 to 50000 |
| **`energy_storage`** | float | W | **TARGET**: Thermal mass charge/discharge | -10000 to 10000 |

## Data Types

### Parquet Format

All datasets are stored in Apache Parquet format with:
- **Compression**: Snappy
- **Encoding**: Plain for integers, dictionary for low-cardinality strings
- **Row group size**: 100,000 rows

### String Fields

- `scenario_id`: Format `scenario_%05d` (zero-padded)
- `climate_zone`: ASHRAE climate zone codes
- `wall_type`: Construction type identifier
- `hvac_mode`: Operating mode enum

### Numeric Fields

All numeric fields use `float64` except:
- `timestep`: `int32`
- `hour_of_day`: `int32`
- `day_of_year`: `int32`
- `num_layers`: `int32`

---

## Validation Rules

### Data Quality Checks

1. **No missing values**: All fields must be non-null
2. **No infinite values**: All numeric fields must be finite
3. **Range validation**: Each field must be within documented bounds
4. **Energy balance**: For zone thermal, `Q_cond + Q_solar + Q_vent + Q_int + Q_HVAC ≈ 0` (residual < 0.1%)

### Target Distribution

- Standard deviation of targets must be > 0.5
- Targets must not be constant across all records

### Coverage Requirements

| Requirement | Minimum |
|-------------|---------|
| Climate zones covered | All 14 zones (1A-8) |
| Building thermal time constants | 0.5h to 12h |
| Exterior temperature range | -30°C to 50°C |
| Solar radiation range | 0-1200 W/m² |

---

## Train/Val/Test Split

### Split Strategy

- **Unit of split**: Scenario (not timestep)
- **Train**: 80% of scenarios
- **Validation**: 10% of scenarios
- **Test**: 10% of scenarios (held out until final evaluation)

### Reproducibility

Split is deterministic based on `seed` parameter. Same seed always produces same split.

## Usage

### Loading in Python

```python
import pandas as pd

# Load zone thermal training data
train = pd.read_parquet("data/synthetic/v2.1/zone_thermal/train.parquet")
val = pd.read_parquet("data/synthetic/v2.1/zone_thermal/val.parquet")
test = pd.read_parquet("data/synthetic/v2.1/zone_thermal/test.parquet")

# Load metadata
import json
with open("data/synthetic/v2.1/zone_thermal/metadata.json") as f:
    metadata = json.load(f)

# Features and targets
feature_cols = [c for c in train.columns if not c.startswith("zone_temp_next") and c != "hvac_power" and c != "energy_storage"]
target_cols = ["zone_temp_next", "hvac_power", "energy_storage"]
```

### Loading in Rust

```rust
use polars::prelude::*;

// Load using polars
let train = ParquetReader::new(File::open("data/synthetic/v2.1/zone_thermal/train.parquet")?)
    .finish()?;
```
